# Chimera
A simple documentation of a custom split keyboard I'm making from absolute scratch. 


Initially, building this keyboard was a passion project of mine that spurred from my love for making my own customized peripherals. I've started and since built keyboards using various pre-assembled parts and layouts. My interest in ergonomics from one of my recent courses led me to research about different peripheral layouts, and was the basis that this project came from.

My hope was to document this journey, the steps I've been taking and hopefully provide a BOM and guide to rebuild this on your own after its done!
